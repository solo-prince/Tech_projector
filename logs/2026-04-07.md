## 🚀 Project Update - IoT Mobile Platform V2

**Date:** 2026-04-07

**Progress:**
- Completed initial integration and calibration of the core navigation sensors (Lidar and Ultrasonic array).
- Successfully implemented basic motion control (forward/backward movement) and rudimentary obstacle avoidance logic on the embedded platform.

**Technical Work:**
- **Sensor Integration:** Finalized physical mounting and wiring for the RPLIDAR A1M8 unit (Lidar) and a 4-sensor HC-SR04 ultrasonic array. The Lidar is currently operating in low-resolution mode for rapid prototyping.
- **Microcontroller & Motor Control:** The main logic runs on an ESP32-WROOM-32E module. Developed a custom state machine in C++ (using ESP-IDF) to manage motor drive signals via an L298N driver shield. Implemented PWM-based speed control for the two DC motors.
- **Obstacle Avoidance Logic:** Initial logic uses a simple threshold approach based on ultrasonic sensor readings. If any sensor registers a distance below 20cm, movement stops and the platform attempts a small turn to clear the path.

**Issues & Fixes:**
- **Issue:** High-frequency electrical noise from the DC motors caused inconsistent readings from the ultrasonic sensors, especially during acceleration.
- **Fix:** Added 100nF ceramic capacitors across the motor terminals to suppress voltage spikes. Also implemented a software-based moving average filter on the sensor readings to smooth out transient noise.
- **Issue:** Initial motor calibration resulted in inconsistent forward movement due to differences in individual motor characteristics ("motor skew").
- **Fix:** Adjusted the PWM values for each motor individually (e.g., left motor required 10% higher PWM for the same speed) during the forward movement state. This will be replaced by encoder feedback in future iterations.

**Next Steps:**
- Integrate motor encoders for closed-loop control (PID tuning) to ensure precise velocity and distance tracking.
- Begin development of the MQTT communication module to allow remote control and data logging via a central server (AWS IoT Core).
- Start work on SLAM (Simultaneous Localization and Mapping) implementation using the Lidar data.
